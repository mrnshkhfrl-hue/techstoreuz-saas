# Руководство по развертыванию магазина (White-label)

Этот проект настроен как White-label решение. Это значит, что для развертывания нового магазина или передачи его новому клиенту **не требуется изменять исходный код**. Все настройки, от названия магазина до контактных данных, управляются через переменные окружения.

## 1. Подготовка `.env`

В корне проекта создайте файл `.env` со следующим содержимым:

```env
# ==========================================
# ОСНОВНЫЕ НАСТРОЙКИ МАГАЗИНА (White-label)
# ==========================================
NEXT_PUBLIC_STORE_NAME="TechStoreuz"
NEXT_PUBLIC_STORE_CURRENCY="UZS"
NEXT_PUBLIC_CONTACT_PHONE="+998901234567"
NEXT_PUBLIC_APP_URL="https://your-domain.vercel.app"

# ==========================================
# НАСТРОЙКИ ТЕЛЕГРАМ БОТА
# ==========================================
# Токен бота, полученный от @BotFather
TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН_БОТА"
# Для совместимости с некоторыми скриптами можно продублировать:
BOT_TOKEN="ВАШ_ТОКЕН_БОТА"

# ID администраторов через запятую (получить можно у @userinfobot)
ADMIN_CHAT_IDS="123456789,987654321"

# ==========================================
# БАЗА ДАННЫХ
# ==========================================
DATABASE_URL="file:./dev.db"
```

## 2. Переменные окружения (Обязательные)

- `NEXT_PUBLIC_STORE_NAME`: Имя вашего магазина. Будет отображаться в заголовке, админ-панели и мини-приложении.
- `NEXT_PUBLIC_CONTACT_PHONE`: Основной номер телефона магазина. Подставляется в карточку товара и детали.
- `NEXT_PUBLIC_APP_URL`: Ссылка на ваш хостинг (например, Vercel). Обязательно без слеша на конце. Используется ботом для кнопок "Перейти в админку".
- `TELEGRAM_BOT_TOKEN`: Токен бота.
- `ADMIN_CHAT_IDS`: Массив Telegram ID тех пользователей, которым будет доступна админ-панель и которым будут приходить уведомления о заказах. Разделяйте запятыми без пробелов.

## 3. Запуск и Развертывание

1. **Установите зависимости:**
   ```bash
   npm install
   ```

2. **Примените миграции базы данных:**
   ```bash
   npx prisma db push
   npx prisma generate
   ```

3. **Запуск сервера (Development):**
   ```bash
   npm run dev
   ```

4. **Деплой на Vercel / другой хостинг:**
   - Подключите репозиторий.
   - Обязательно скопируйте все переменные из вашего `.env` в панель настроек `Environment Variables` на Vercel.
   - Базу данных SQLite рекомендуется заменить на PostgreSQL (Neon.tech, Supabase) для production, изменив `DATABASE_URL` и `provider = "sqlite"` на `provider = "postgresql"` в `schema.prisma`.

5. **Запуск бота (Polling для локальной разработки):**
   Бот находится в папке `bot`. Он автоматически подхватит переменные из корня.
   ```bash
   cd bot
   pip install -r requirements.txt
   python main.py
   ```
   *Для production бота следует перевести на вебхуки или использовать отдельный сервис-раннер (Railway, Render).*

## 4. Как работает White-Label

- При старте `Next.js` проверяет переменные через файл `lib/env.ts`. Если критически важных данных нет, сборка упадет с ошибкой (fail-safe).
- Ссылки на Telegram и контактные данные в `ProductCard`, `ProductDetail` и `CartPanel` подтягиваются динамически.
- Логика "Б/У" или "Новый" для товаров встроена в ядро (с автоматической фиксацией остатка `stockCount = 1` для Б/У).
- Магазин адаптируется к Telegram (WebApp.expand), а UI-тема автоматически подхватывает системную (с возможностью ручного переключения в шапке).
